# Get started

Rehive exposes three products behind one consistent API: **Identity**,
**Money** and **Compliance**. This section covers what you need before you
build with any of them.

1. **[The model](/get-started/the-model)**: the handful of objects everything is built from.
2. **[Quickstart](/get-started/quickstart)**: a verified, funded customer in a few calls.
3. **[Authentication](/get-started/authentication)**: API keys, base URL and environments.

## What you never deal with

Rehive runs a multi-asset ledger underneath, but you never configure it. There's
**no currency setup or ledger configuration** at the API level. Those concepts
don't exist in this surface. You open a Wallet for a customer and it behaves the
way the use case needs.

If you genuinely need the low-level primitives, they live behind
[Advanced](/advanced), gated, and not the default path.
