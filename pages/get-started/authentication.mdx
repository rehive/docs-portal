# Authentication

All requests use a secret API key as a bearer token.

```
Authorization: Bearer sk_live_...   # live
Authorization: Bearer sk_test_...   # test
```

| | |
|---|---|
| **Base URL** | `https://api.rehive.com/v1` |
| **Format** | JSON. Amounts are decimal strings in the resource currency — divisibility is handled for you. |
| **IDs** | Prefixed: `cus_` · `acc_` · `txf_` · `pyt_` · `evt_` |
| **Environments** | `sk_test_` runs the full object lifecycle against simulated rails. |

Keep secret keys server-side. Rotate them from the dashboard.
