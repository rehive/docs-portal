# Funding instruments

A **funding instrument** is a way to move money in or out of an account: a
**virtual bank account**, an on-chain **address**, or a **card**. They attach to
an account — you don't manage them as separate objects.

```sh
curl https://api.rehive.com/v1/accounts/acc_3RtZ0/funding-instruments \
  -H "Authorization: Bearer sk_test_..." \
  -d type=virtual_account -d currency=USD
```

```json
{
  "id": "fi_2Kc9",
  "type": "virtual_account",
  "currency": "USD",
  "details": { "account_number": "•••• 8841", "routing_number": "•••• 0021", "rail": "ach" },
  "status": "active"
}
```

You can also provision endpoints **without a balance** — see ledger-optional in
[Assets & custody](/accounts/assets-custody).

## Terminology

If you've integrated other providers, "account" and "wallet" are overloaded.
Here's the mapping:

| Concept | Rehive | Bridge |
|---|---|---|
| A held balance | **Balance** (in an Account) | Wallet |
| A fiat receive endpoint | **Funding instrument** (virtual account) | Account |
| On-chain custody/address | **Funding instrument** (address) | (in Wallet) |
| Movement | **Transfer / Payout** | Orchestration / Payout |

In short: a Rehive **Account** is a *balance*; a virtual bank account is a
*funding instrument on it*, not a separate object.
