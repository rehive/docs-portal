# Guides

> First-stab shapes, illustrative, not a frozen contract.

End-to-end walkthroughs that compose the products into a real program. Each one
uses the same conventions: [prefixed IDs, pagination, idempotency and
versioning](/get-started/conventions), the shared [error
envelope](/get-started/errors) and [webhooks](/get-started/webhooks).

| Guide | For |
|---|---|
| [Global dollar account](/guides/global-dollar-account) | A fintech launching USD accounts: customer to verified, funded wallet, inbound deposit and an outbound cross-border payment, with the blocked path shown. |
| [Mass payout](/guides/mass-payout) | Payroll and disbursements: one Payment with many destinations, per-destination status, reconciliation and events. |
| [Add compliance to your ledger](/guides/add-compliance-to-your-ledger) | Bring your own ledger: connect KYC and a transaction feed, adopt a control baseline, pull an evidence report. |

New here? Start with the [model](/get-started/the-model) and the
[quickstart](/get-started/quickstart), then come back for the full flow.
